# Chaining Selectors

> Exercise 04 from The Odin Project - CSS Foundations

## Objective

Practice chaining selectors to target elements that have multiple classes.

## What I practiced

- Chaining multiple class selectors
- Selecting elements with more than one class
- Understanding the difference between chained selectors and descendant selectors
- Applying specific styles to elements with combined classes
- Using CSS properties such as:
  - `width`
  - `height`
