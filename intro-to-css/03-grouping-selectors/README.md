# Grouping Selectors

> Exercise 03 from The Odin Project - CSS Foundations

## Objective

Practice grouping multiple selectors that share the same CSS properties.

## What I practiced

- Grouping selectors with commas
- Applying the same styles to different elements
- Avoiding repeated CSS rules
- Adding specific styles to individual selectors
- Using a font fallback list with `font-family`
