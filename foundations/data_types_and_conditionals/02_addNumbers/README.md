# Add Numbers

Exercise from The Odin Project focused on working with JavaScript functions and parameters.

## Objective

Create a function that receives two numbers and returns their sum.

Example:

```js
addNumbers(1, 1);
```

Expected result:

```text
2
```

## Concepts practiced

- JavaScript functions
- Function parameters
- `return`
- `module.exports`
- Basic testing with Jest
- Running tests with npm
