# Odin Recipes

This is my first project from [The Odin Project](https://www.theodinproject.com/).

The goal of this project is to practice the basic concepts of HTML by creating a simple recipe website.

## About the Project

The website contains a homepage with links to five different recipes:

- Beef Stroganoff
- Lasagna
- Carrot Cake
- Chocolate Chip Cookies
- Garlic and Oil Pasta

Each recipe page includes an image, a list of ingredients, and step-by-step preparation instructions.

## Skills Practiced

During this project, I practiced:

- Creating HTML pages
- Using headings and paragraphs
- Creating ordered and unordered lists
- Adding images
- Creating links between pages
- Organizing files and folders
- Using Git and GitHub

## Technologies

- HTML
- Git
- GitHub

## Project Structure

The project contains a main `index.html` page and separate pages for each recipe.
