# Odin Recipes

Odin Recipes is a simple recipe website created as part of my studies with The Odin Project.

The project started as a basic HTML exercise and was later expanded into a complete landing page to practice HTML, CSS, Flexbox, page structure, styling, and navigation.

## Features

- Custom Odin Recipes visual identity
- Header with navigation links
- Intro section with project presentation
- Recipe showcase
- Cooking quote section
- About section with a link to The Odin Project
- Footer with copyright information
- Navigation to the original recipe project

## What I practiced

- Structuring pages with semantic HTML
- Working with links and navigation
- Using Flexbox for page layouts
- Aligning and spacing elements
- Creating reusable CSS classes
- Styling buttons and links
- Organizing images and text
- Using `gap`, `padding`, and `margin`
- Working with `flex-grow`, `flex-shrink`, and alignment
- Creating sections with different layouts
- Improving an existing project with a custom design

## Technologies

- HTML
- CSS
- Flexbox
