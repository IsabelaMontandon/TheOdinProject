# Intro to CSS

This folder contains the introductory CSS exercises from The Odin Project's Foundations course.

These exercises focus on the basics of applying CSS and using different types of selectors to style HTML elements.

## Exercises

### 01 - CSS Methods

Practice the three main ways of adding CSS to HTML:

- External CSS
- Internal CSS
- Inline CSS

### 02 - Class and ID Selectors

Practice selecting and styling elements using:

- Class selectors
- ID selectors

### 03 - Grouping Selectors

Practice grouping multiple selectors that share the same CSS properties.

### 04 - Chaining Selectors

Practice chaining class selectors to target elements that have multiple classes.

Example: `.avatar.proportioned`

### 05 - Descendant Combinator

Practice selecting elements based on their position inside another element.

Example: `.container .text`

## What I practiced

Throughout these exercises, I practiced:

- Linking CSS files to HTML
- Using external, internal and inline CSS
- Using class selectors
- Using ID selectors
- Grouping selectors
- Chaining selectors
- Using descendant combinators
- Applying styles to specific HTML elements
- Understanding how selectors target different elements

I also practiced CSS properties such as:

- `color`
- `background-color`
- `font-size`
- `font-family`
- `font-weight`
- `text-align`
- `width`
- `height`
