# Flexbox Exercises

Collection of Flexbox exercises from The Odin Project Foundations course.

These exercises helped me practice how Flexbox works in different layouts, starting with simple alignment and spacing and progressing to complete page structures with headers, sidebars, content areas, cards, and footers.

## What I practiced

- Using `display: flex`
- Understanding flex containers and flex items
- Working with the main axis and cross axis
- Using `flex-direction`
- Aligning items with `justify-content` and `align-items`
- Creating spacing with `gap`
- Using `flex-grow` to fill remaining space
- Preventing elements from shrinking with `flex-shrink`
- Using `flex-wrap` to create responsive layouts
- Structuring nested Flexbox containers
- Organizing headers into left and right sections
- Centering content horizontally and vertically
- Building modal layouts
- Creating full-page layouts
- Building sidebars and responsive card sections

## Exercises

- `01-flex-center` — Centering elements with Flexbox
- `02-flex-header` — Creating a header with aligned sections
- `03-flex-header-2` — Practicing spacing and nested flex groups
- `04-flex-information` — Organizing information cards horizontally
- `05-flex-modal` — Building a modal with nested Flexbox containers
- `06-flex-layout` — Creating a complete page with header, content, and footer
- `07-flex-layout-2` — Building a layout with sidebar, responsive cards, and wrapping

## Key Concepts

One of the most important concepts practiced in these exercises is that `display: flex` controls only the direct children of a flex container.

This made it necessary to create additional containers in some exercises in order to organize groups of elements separately.

Another important concept was understanding how properties such as `flex-grow`, `flex-shrink`, and `flex-wrap` affect how elements behave when the available space changes.
