# Block and Inline

This folder contains the block and inline exercises from The Odin Project's Foundations course.

These exercises focus on understanding spacing, sizing and the CSS box model through margin and padding.

## Exercises

### 01 - Margin and Padding 1

Practice using margin and padding to control the spacing and positioning of block elements.

Main concepts:

- `margin`
- `padding`
- `width`
- Borders
- Background colors
- Using `margin-left: auto` to align an element to the right

### 02 - Margin and Padding 2

Practice using margin and padding in a card layout with multiple sections.

Main concepts:

- Spacing between elements
- Spacing inside elements
- Nested block elements
- Default margins from HTML elements
- Card layout structure
- `box-sizing`

## What I practiced

Throughout these exercises, I practiced:

- Understanding the CSS box model
- Using margin to create space outside elements
- Using padding to create space inside elements
- Controlling the width of block elements
- Working with borders
- Adjusting spacing between different sections
- Aligning elements using margin
- Understanding how default browser styles can affect spacing
